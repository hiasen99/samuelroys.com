Small, sharp tools that each solve one specific problem well.

Every tool below started the same way: something needed to exist, and it didn't. A timing sheet that actually did the math. A worksheet generator that printed correctly the first time. Ideas that used to die right there, because the gap between this should exist and this exists was months of work I couldn't do.

That gap is gone. These are built with AI — I describe the problem precisely, and the thing gets made. None of them would be here otherwise. They're all free, fast, and run entirely in your browser.

Things I've built

Timing Calculator

Works out episode record targets from an air total. Budget your segments, inserts and fixed times, and it tells you exactly how long the cold open has to run to land the episode on the nose. Everything saves as you type.

Cursive Handwriting Practice Sheets
